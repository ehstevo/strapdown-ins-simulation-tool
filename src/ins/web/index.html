INS Monte Carlo Studio

Configure a trajectory, initial-condition uncertainty, and inertial sensor error model. The form saves the same TOML configuration used by the command-line simulator.

All error distributions have a fixed zero mean. State vectors use North / East / Down; IMU vectors use body x / y / z.

Simulation

Monte Carlo ensemble size, time base, and output location.

Truth Scenario

Vehicle truth trajectory used to generate ideal IMU measurements.

Initial Navigation-State Error

Each standard deviation defines an independent run-to-run Gaussian distribution with a fixed zero mean.

Gyroscope Error Model

Body-axis rate errors. ARW is white measurement noise; the bias rate random walk is an unbounded bias state.

Accelerometer Error Model

Body-axis specific-force errors. VRW is white measurement noise; the bias rate random walk is an unbounded bias state.

Run Simulation

The local server runs the ensemble in the background and writes the report, statistics, and resolved TOML configuration to the chosen output directory.
